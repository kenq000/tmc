# Welcome to TMC Project - Scripting Structure.

# The Core
The `"core"` folder stands for ServerScriptService itself.
Literally EVERY script you'll see in ServerScriptService, will be a folder and it's main script inside of it.

Now, the `"Utils"`, folder inside the children folder from `"core"` are workers for the script that is currently running them
- Other Folders -
This is for organized functions, etc.

# Other Instances
Instances like children of `"etc"` are likely animations/knifes/guns/maps.
They all should be organized and be RBXM/RBXMX for loading.
